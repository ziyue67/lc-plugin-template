# LeetCode 插件模板

一个多语言的 LeetCode 刷题模板库，提供 C++、Python、Go、Java 和 JavaScript 的题目解决方案，适合作为本地练习、教学演示与自动化评测模板。

## 项目简介

本项目整理了 LeetCode 经典算法题目的解决方案，包含完整的代码实现和常用数据结构模板，旨在帮助开发者快速开始刷题并提高编程能力。

### 核心特性

- ✅ **C++ 题目全部包含测试用例 main 函数** - 可直接编译运行验证
- ✅ **多语言支持** - C++、Python、Go、Java、JavaScript
- ✅ **单文件答案** - 便于快速编译/运行
- ✅ **完整数据结构** - 链表、树等公共定义
- ✅ **详细中文注释** - 便于理解学习

### C++

#### 编译运行

**单文件快速编译（推荐）**：
```bash
# Linux/macOS
g++ -std=c++20 "cpp-template/1.两数之和.cpp" -o test && ./test

# Windows (PowerShell)
g++ -std=c++20 "cpp-template/1.两数之和.cpp" -o test.exe && .\test.exe

# 静态链接（Windows推荐）
g++ -std=c++20 -static "cpp-template/XX.题目名.cpp" -o test.exe && .\test.exe
```

**使用 CMake**：
```bash
cmake -S cpp-template -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -- -j
```

### Go
- 运行包内所有测试：
  - go test ./...
- 运行单个测试：
  - go test ./go-template/leetcode/editor/cn -run TestName
- 格式化：gofmt -w .

### Python
- 运行单文件脚本：
  - python3 python-template/leetcode/editor/cn/merge-two-sorted-lists.py
- pytest（若添加测试）：
  - pytest -q path/to/test_file.py::test_name
- 格式化：black .；导入排序：isort .

### JavaScript / Node
- 运行单文件：
  - node js-template/leetcode/editor/cn/merge-two-sorted-lists.js
- 测试（若添加）：
  - npx jest path/to/test.spec.js -t "test name"
- 格式化/校验：prettier --write .；eslint .

### Java (Maven)
- 构建：mvn -f java-template/pom.xml compile
- 测试：mvn -f java-template/pom.xml test
