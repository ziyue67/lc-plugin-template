# LeetCode 插件模板

一个多语言的 LeetCode 刷题模板库，提供 C++、Python、Go、Java 和 JavaScript 的题目解决方案。

## 项目简介

本项目整理了 LeetCode 经典算法题目的解决方案，包含完整的代码实现和常用数据结构模板，旨在帮助开发者快速开始刷题并提高编程能力。

## 目录结构

```
lc-plugin-template/
├── cpp-template/          # C++ 模板和题解
├── python-template/       # Python 模板和题解
├── go-template/          # Go 模板和题解
├── java-template/        # Java 模板和题解
├── js-template/          # JavaScript 模板和题解
├── common/               # 通用数据结构定义（链表、树等）
├── build/                # 构建相关文件
└── ctoon_example/        # 示例代码
```

## 语言模板

### C++ 模板 (33+ 题目)

包含常用的 LeetCode 题目解法，涵盖以下主题：

- **链表**：反转链表、合并有序链表、环形链表、相交链表等
- **数组**：双指针、滑动窗口、移动零、删除重复项等
- **字符串**：反转字符串、回文串验证、最长公共前缀等
- **树**：二叉树遍历、路径问题等

特色题目：
- 二进制链表转整数
- 图书整理 I
- 合并两个有序链表
- 删除链表的倒数第 N 个结点

### Go 模板

### Java 模板

## 通用数据结构

`common/` 目录包含常用的数据结构定义：

- `ListNode.cpp` - 链表节点定义
- `TreeNode.cpp` - 二叉树节点定义

## 使用方法

### 1. 克隆仓库

```bash
git clone https://github.com/ziyue67/lc-plugin-template.git
cd lc-plugin-template
```

### 2. 选择语言模板

进入对应语言的目录：

```bash
cd cpp-template  # 或 python-template, go-template 等
```

### 3. 查看和运行代码

- 每个文件对应一道 LeetCode 题目
- 文件名包含题号和题目名称
- 代码包含详细的注释说明

## 主要特性

- 多语言支持：C++、Python、Go、Java、JavaScript
- 代码注释完整：每个解决方案都有清晰的注释
- 数据结构完备：提供常用的链表、树等数据结构定义
- 实用算法：涵盖面试高频算法题
