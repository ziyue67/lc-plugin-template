# LeetCode C++ 题目解答

这是一个 LeetCode 题目的 C++ 实现项目，包含了数据结构和算法的学习与练习。

## 项目概述

本项目主要用于学习和巩固数据结构与算法基础知识，包含简单、中等和困难难度的题目实现。适合初学者以及想要复习基础知识的进阶学习者。

## 开发环境

- **编译器**: Visual Studio 2022/2026 或兼容的 C++ 开发环境
- **语言标准**: C++20 (主要), 部分配置支持 C++11
- **平台**: 支持 Win32 (x86) 和 x64 架构

## 编译运行

### 使用 g++ 命令行

```bash
# 单个文件编译运行示例
g++ -std=c++20 "125.验证回文串.cpp" -o main && ./main
g++ -std=c++20 "206.反转链表.cpp" -o reverse && ./reverse
g++ -std=c++20 "1.两数之和.cpp" -o two_sum && ./two_sum
```

### 使用 Visual Studio

1. 打开项目文件夹
2. 选择对应的 .cpp 文件
3. 按 F5 编译运行
